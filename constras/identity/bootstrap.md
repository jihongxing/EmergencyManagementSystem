# 组织及首位管理员开通契约

状态：`MODULE CONTRACT`。任务：`P1-02`。依据：[身份与权限 SSOT](../../docs/ssot/04-access.md)、[身份模块契约](module.md)、[P1-02 任务](../../docs/development-tasks.md)。

## 边界

- 入口仅供受控实施适配器调用，不是公开注册，也不是日常第五角色。
- 组织类型只接受 `enterprise` 和 `department`；首位管理员角色分别为 `enterprise_admin` 和 `department_admin`。
- 开通必须提供稳定 `externalKey`、至少一条已核验材料和受控操作人标识。
- 开通创建组织和 `pending` 首位管理员；不接受、不保存初始密码。
- 同一 `externalKey`、同一组织内 `loginId` 或重复首位管理员均拒绝。
- 更换首位管理员必须再次提供已核验材料；旧成员变为 `revoked`，新成员为 `pending`，并写入审计和材料来源。
- 失败必须整体回滚，不得留下半个组织、孤立成员或孤立材料。
- 审计不得保存密码、密码哈希、原始凭据或恢复令牌。

## 验收场景

| 场景 | 结果 |
| --- | --- |
| 已核验材料开通新组织 | 创建组织、待激活首位管理员、材料记录和审计记录 |
| 缺材料或材料未核验 | 拒绝，状态为外部输入未核验 |
| 重复 `externalKey` | 拒绝，状态为冲突 |
| 首位管理员更换 | 旧成员撤销、新成员待激活，材料和审计均留痕 |
| 普通业务身份调用 | 不进入该服务边界；由受控适配器先行拒绝 |
| 任一持久化步骤失败 | 事务回滚 |
