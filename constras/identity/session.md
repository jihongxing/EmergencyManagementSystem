# 会话与逐次身份校验契约

状态：`MODULE CONTRACT`。任务：`P1-03`。依据：[身份模块契约](module.md)、[生命周期案例](lifecycle.json)、[身份 OpenAPI](identity.openapi.json)、[权限 SSOT](../../docs/ssot/04-access.md)。

## 最小范围

- 首次密码设置只允许受控实施服务调用，`pending` 成员未激活前不能登录；不开放公众注册或认领。
- 登录成功只为 `active` 成员创建会话。成员、组织任一非活动状态均拒绝受保护请求。
- Web 会话使用不可预测的服务端 Cookie；Flutter 返回短期访问令牌和可撤销刷新令牌。服务端只保存令牌哈希。
- 刷新令牌一次性轮换；旧刷新令牌立即失效，重复使用拒绝。
- 退出立即撤销当前会话；撤销、过期或未知凭据均拒绝后续请求。
- 每次受保护请求都按服务端会话重新读取成员和组织当前状态；客户端携带的角色、组织和工作区选择不参与授权。
- 密码恢复请求统一返回 `202`，不泄露登录标识是否存在；确认令牌一次性、短时有效并在成功后撤销其他会话。
- 错误密码、未知登录标识和失效凭据不得返回账号存在性、密码哈希、令牌原文或恢复令牌。

## 数据与时间

- 访问会话短期有效，刷新会话有效期更长；具体时长由实现配置注入，测试使用显式时钟。
- 密码使用不可逆哈希保存；数据库和日志不得保存明文密码。
- 会话、刷新令牌和恢复令牌都使用随机原文，仅向必要客户端返回一次；持久化只保存哈希。

## 验收场景

| 场景 | 结果 |
| --- | --- |
| active 成员正确密码登录 | 返回会话；Web 设置 HttpOnly Cookie，Flutter 返回访问/刷新令牌 |
| 错误密码或未知登录标识 | 统一 `401 authentication_failed` |
| pending/suspended/revoked 成员登录 | `403 member_inactive` |
| 会话有效但成员随后撤权 | 下一次受保护请求拒绝 |
| 组织随后停用 | 下一次受保护请求拒绝 |
| 刷新令牌重复使用 | 拒绝，旧令牌不能恢复 |
| 退出后重放 | `401 authentication_required` |
| 恢复请求未知账号 | 仍返回 `202`，不泄露账号存在性 |
| 恢复令牌重复使用或过期 | 拒绝 |
