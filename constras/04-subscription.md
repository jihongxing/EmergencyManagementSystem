# 免费与订阅权益契约

状态：`DERIVED CONTRACT`。依据：[01-product](../docs/ssot/01-product.md)、[04-access](../docs/ssot/04-access.md)。应用商店与支付渠道仍见[OPEN](../docs/OPEN.md)。

## 不变量

- `C04-01` 订阅以签约组织而非场所、对象、二维码或人员计费；企业/物业自愿购买。试售价格为月付 39 元、季付 108 元、年付 398 元；该价格不是对盈利或长期售价的保证。
- `C04-02` 未订阅组织完整拥有逐场所人员与对象管理、工作分配、自检、证据上传、问题整改、自主复查和完整本组织历史；必要监管交互及依法必要的记录查看与提交不设付费门槛。不得通过人为降低免费操作质量、必要人员/扫码/次数限制诱导购买。
- `C04-03` 订阅仅给本组织管理员提供跨场所自检/整改/复查待办与进度汇总、批量提醒或分配本组织工作；不能买到合规资格、行政检查权益、监管数据、额外行政权限或跨组织访问。提醒依据已确认的适用规则或组织自身内部安排，不创造法定周期。
- `C04-04` 服务端维护并核验组织权益；只有服务端确认的支付结果才能开通付费权益，客户端成功提示不可单独授权。到期仅关闭上述跨场所汇总与批量便利，保留免费流程、历史记录及必要监管交互；不得删除或遮挡既有记录。
- `C04-05` 首期以组织级 Web 购买流程为设计入口，Flutter 读取服务端权益；不得默认在 App 中引导站外付款。App 内购买入口、渠道、开票、退款及续费细则仍待实际分发规则和运营方案核验，未定部分不能作为已批准实现。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 未订阅组织逐场所完成自检、整改及复查 | 与已订阅组织具有同等基础完成能力 |
| 付款页显示成功但服务端未确认结果 | 不开通跨场所工作台权益 |
| 已订阅组织查看其他组织工作台数据 | 拒绝；权益不扩大授权 |
| 订阅到期后访问跨场所汇总或批量分配 | 便利功能停止；仍可逐场所操作和查看全部本组织历史 |
| 未确定应用商店规则却在 Flutter 中引导 Web 支付 | 不符合契约，不得上线该购买引导 |
