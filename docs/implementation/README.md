# 试点实施输入

状态：`EXTERNAL INPUT`，不是软件产品 SSOT，也不是已取得的行政授权。本目录记录实施时由有权主体提供、核验和确认的事实与规则；目前尚未填入任何具体县、部门或检查清单。

| 输入 | 提供与确认方 | 软件使用边界 |
| --- | --- | --- |
| 试点县、行政区划及场所实际地址归属资料 | 项目实施方取得并与试点有权主体核验 | 地址明确归属后才可用于自动匹配；不以单位注册地址替代实际场所 |
| 监管部门身份、职责范围及数据共享授权 | 试点有权主体 | 配置部门适用范围和可见性；系统存储本身不是查阅许可 |
| 适用事项、标准/规则、版本及效力期 | 有权发布或确认的主体 | 只承载和执行经核验的内容；不得据软件模板创设检查标准 |
| 企业自检适用的法定最低频次和企业制度 | 有权规则来源及企业自身制度 | 区分来源与效力，不代替法律判断 |
| 临时行政检查的合法启动情形、人员及程序依据 | 试点有权部门 | 扫码是软件入口，不是执法授权；未核验时不形成正式行政记录 |
| 首位管理员单位授权材料与部门指定材料 | 各组织、试点部门 | 仅开通平台管理身份，不确认行政职责或执法资格 |

取得资料时应登记：来源、发布/确认主体、原件或可核验出处、适用对象/区域、版本、生效与失效时间、核验人和核验日期、是否允许系统内使用。资料变化须保留旧版本及其对应历史记录。

**待核验的默认行为：**地址/监管范围不明则进入人工待处理；检查事项、频次和临时检查依据不明则不标示为合法或合规结论。具体产品行为分别见 [权威边界](../ssot/02-authority.md)、[场所身份](../ssot/03-site-identity.md) 和 [现场流程](../ssot/05-workflows.md)。

第一批单位、设施、清单和试点地区均由实际实施决定，不由软件 SSOT 预设。
